# oddatui 🦀 📊

**oddatui** is a Terminal User Interface (TUI) written in Rust, designed for fetching, managing, and predictively analyzing antepost betting odds across multiple sports.

Inspired in philosophy and name by the `ratatui` library, the software is built to run entirely within your local network. It provides a lightweight and centralized tool to support personal betting strategies without relying on heavy web interfaces.

### 💡 Key Features
* **Lightweight TUI:** Developed in Rust to guarantee high performance, responsiveness, and minimal resource consumption directly from the terminal.
* **API Call Optimization:** Implements a smart local caching strategy to maximize data effectiveness and minimize the consumption of free API plans (e.g., The Odds API).
* **Multi-Sport Architecture:** Designed from the ground up with a modular data structure, ready to accommodate and manage schedules and odds for various sports and events over time.
* **Antepost Focus:** Optimized for analyzing market movements and odds variations before events begin.
